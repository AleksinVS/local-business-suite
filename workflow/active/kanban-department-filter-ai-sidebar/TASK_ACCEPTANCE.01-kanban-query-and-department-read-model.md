# Приемка пакета 01

Статус: Accepted.

Серверная выдача начинается с доменного селектора видимых заявок, а фильтр разрешается
только внутри доступных подразделений. Канонический URL, старые ссылки и пограничные
наборы ID покрыты HTTP- и интеграционными тестами. Ослабления `department_branch` не
обнаружено.
