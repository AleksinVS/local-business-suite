# Приёмка: один Save для администрирования доступа

Дата: 2026-08-24
Пакет: `20-direct-save-access-administration`
Вердикт: принят после полного проверочного барьера.

## Принято

- Обычные редакторы пользователя, роли, состава роли, доски и групп памяти
  отправляют один POST `action=save`; браузер не получает preview-токены и не
  показывает отдельные подтверждения риска.
- Успешный HTMX Save не перезагружает документ, обновляет панель и таблицу,
  снимает busy-состояние и переводит фокус на сообщение результата.
- Ошибка и тайм-аут сохраняют черновик, снимают блокировку интерфейса и позволяют
  повторить сохранение.
- Сервер повторно проверяет активного автора, цель, версию контракта и предметную
  политику под общей блокировкой; транзакции, privilege ceiling, защита
  суперпользователя, атомарная запись контракта и аудит сохранены.
- Единая карточка пользователя либо сохраняет все изменённые компоненты, либо
  откатывает их вместе с аудитами при сбое позднего компонента.
- AI PendingAction, Django Admin break-glass и общий редактор runtime-настроек
  сохранили отдельные подтверждения. Общий шаблон доски условно показывает один
  Save в продуктовой странице и прежний preview/apply только в Django Admin.

## Независимая критика и исправление

Luna-критик дал PASS без S1-находок. По его замечаниям обновлены активный план и
workflow, удалён мёртвый переходный код product views. Внутренние
preview/apply-функции оставлены как временная серверная реализация публичных
`save_*` команд и явно описаны в ADR-0042.

Основной агент дополнительно обнаружил и исправил общий шаблон доступа к доске,
который без условной ветки ломал бы резервный Admin-путь. Для обеих веток добавлены
регрессионные проверки разметки и реального применения.

## Самостоятельная визуальная проверка

- Осмотрены фактические снимки Chromium: пользователь и роль при `1440x1000`,
  пользователь при `320x760`, верхняя и нижняя части панелей.
- Горизонтального переполнения нет; один Save достижим на всех размерах;
  старые тексты preview/confirmation отсутствуют в продуктовых панелях.
- Правая панель блокирует фон как диалог; мобильная версия использует один слой;
  нижняя причина и Save не перекрываются.

## Остаточный риск

Публичный HTTP/UX-контракт уже прямой, но `save_*` временно строит и потребляет
старый подписанный план внутри одного серверного вызова. Это не добавляет шага
пользователю и сохраняет проверенные инварианты, однако редкая ошибка гонки может
содержать историческое слово «предпросмотр». Замена внутреннего токена типизированным
объектом плана допустима отдельным низкорисковым рефакторингом без изменения UI.
