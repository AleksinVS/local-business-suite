# Приемка: базовый просмотр канбана

Статус: принято.

- пользователь без роли видит заявки только своей ветки;
- закрытая для `customer` доска недоступна;
- операции записи возвращают 403;
- кнопка создания скрыта;
- явная роль отменяет встроенный профиль;
- итоговый доступ объясняет источник разрешения.

Покрытие: модульные, HTTP и постоянный e2e-сценарий через management command.
Финальная приемка: `make verify-full` — 605 тестов и 85 подтестов пройдены.
После пересборки контейнера health-check и `default_board_access_e2e` прошли;
операция создания ожидаемо отклонена с HTTP 403.
