# Приёмка: первый безопасный срез

Статус: принято технически, дальнейшие пакеты блока остаются активными.

## Принятые критерии

- superuser self-assignment проходит только через signed preview/apply, риск и аудит;
- manager ограничен allowlist, не меняет собственные и protected roles;
- стандартная Django Admin форма не пишет access-поля, резервный маршрут требует
  active superuser и причину;
- AI generic update не меняет группы и не подтверждает произвольный payload;
- LDAP sync false делает ноль group writes, enabled fail-closed; inactive user и
  stale privileged flags не восстанавливаются;
- технические группы и permissions сохраняются при назначении контрактной роли;
- список и карточка работают в браузерном smoke на desktop и 320px.

## Остаточный риск

Runtime-копия `data/contracts/role_rules.json` может быть осознанно изменена
оператором и не обязана совпадать с дефолтом. Если в ней отсутствует новый
`$administration`, делегированные назначения закрыты до явного обновления рабочей
копии; superuser не блокируется. AD-выдача/отзыв ролей пока не выполняется.

## Следующий gate

Не считать весь ADR-0040 завершённым до пакетов 00c–05 и usability-приёмки.
