# Техническая приёмка

Статус: принято 2026-08-11.

## Критерии

- [x] Отдельная кнопка «Редактировать» отсутствует.
- [x] Автор/менеджер редактирует поля непосредственно в окне просмотра.
- [x] Пользователь только с правом просмотра не видит форму и получает `403` на прямой POST.
- [x] Ошибки формы возвращаются в то же окно.
- [x] Пустые необязательные даты сохраняются как `NULL`.
- [x] Аудит содержит автора и только названия реально изменённых полей.
- [x] PII-значения не дублируются в тексте аудита.
- [x] Изменение и аудит атомарны.
- [x] Целевые, профильные, полные и браузерные проверки прошли.

## Остаточный риск

Предметный аудит гарантирован для штатного пользовательского пути через сервис. Прямые ручные
изменения модели из Django shell или стороннего кода по-прежнему являются административным
обходом сервисного слоя; они не входят в пользовательский сценарий этой задачи.
