# Переход к LBS Factory v3.4

Статус: репозиторная часть P0 проверена, эксплуатационная ожидает отчёта хоста;
реализация P1 не начата. Дата: 2026-10-22.
Владелец: владелец проекта. Исполнение и актуализация: агент текущего этапа.

## Цель и границы

Подготовить переход от существующего портала к согласованной модульной Factory,
сохранив прикладные права и данные. Архитектурный источник —
[план перехода](../../architecture/lbs-factory/05_ROADMAP_AND_ACCEPTANCE.md),
а не этот документ. Детальная разработка CROW ведётся только по документу `12`.

**Уточнение владельца 2026-10-22:** существует одна продуктивная установка
Windows + IIS, использующая лист ожидания. Заявленный сохраняемый состав:
лист ожидания, пользователи, права, подразделения, оборудование. Предыдущее
сообщение об отсутствии продуктивных установок отозвано. Отсутствие используемой
Wiki не доказывает отсутствие автоматически построенных индексов.

P0 читает код и локальную среду, готовит отчёты, ADR и проверки на синтетических
данных. Он не меняет поведение приложений, контракты, рабочие данные, настройки
хостов или развёртывание. Подключения к продуктивному серверу в этом этапе нет.

## Очередность

1. P0: исходный снимок, зависимости, ACCESS-00, PRIV-00, исходные проверки,
   решения и план резервирования/переноса.
2. P1: общий Knowledge API, корректный OKF, немедленная рабочая запись,
   неблокирующий реестр подтверждений; сначала необходимые PRIV/Access-проверки.
3. Остальные этапы P2–P6 — по архитектурному плану и их условиям допуска.
   Модульность предметных приложений обязательна; реализация CROW, сетевого A2A,
   OpenFGA и отдельной службы не является условием первого простого профиля.

## Проверки и приёмка P0

- У каждой существенной зависимости и найденного расхождения есть ссылка на код.
- Исходная семантика прав отделена от желаемой; тесты и пробелы перечислены.
- Настройки Git, локального стенда и продуктивного хоста не смешиваются.
- Есть воспроизводимые локальные проверки и план сохранения продуктивных данных.
- Новые решения не выходят за уже согласованные Factory v3.4 / ADR-0051.
- `.desc.json`, карта проекта, входная документация и очередь актуальны.

Исходный отчёт: [P0](../../architecture/lbs-factory/13_P0_BASELINE.md).
Исполнительный пакет: [lbs-factory-p0](../../../workflow/active/lbs-factory-p0/BLOCK_BRIEF.md).
Репозиторная задача 01 проверена. Эксплуатационная задача 02 не выполнена:
владелец подтвердил отсутствие доступа к серверу и выбрал подготовку проверки
для самостоятельного запуска. Пакет остаётся active до получения результата,
проверки восстановления и итоговой приёмки P0.

## Открытые зависимости

Фактические версия кода, конфигурация IIS/SSO, хранилище ролей, состав данных,
резервная копия и восстановление продуктивного хоста требуют отдельного
обследования перед переносом. Подтверждение пользователем перечня данных не
заменяет проверку внешних ключей, авторства, истории и назначений прав.

Политика персональных данных в Wiki/Git остаётся
[открытым долгом](knowledge-personal-data-git-policy-debt.md); отдельный
синтетический пилот Factory этот долг не блокирует.
