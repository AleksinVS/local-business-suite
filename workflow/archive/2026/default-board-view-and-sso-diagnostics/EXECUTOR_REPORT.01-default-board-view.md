# Отчет исполнения: базовый просмотр канбана

Реализован встроенный профиль `default_board_viewer` для активного
авторизованного пользователя без контрактных ролей.

- область просмотра: ветка подразделения;
- доступны только доски, открытые группе `customer`;
- создание, изменение, комментарии, вложения и переходы запрещены;
- назначение любой контрактной роли полностью заменяет базовый профиль;
- источник профиля показывается в «Итоговом доступе»;
- добавлена HTTP-проверка `default_board_access_e2e` с откатом тестовых данных.

Схема базы и рабочие контракты ролей не менялись.
