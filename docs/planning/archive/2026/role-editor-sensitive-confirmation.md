# Подтверждение чувствительных изменений ролей

Статус: завершено 2026-08-06.

## Цель

Сделать подтверждение критичных прав доступным без зависимости от JavaScript и
не допустить массового отзыва прав из устаревшей вкладки редактора.

## Реализация

- первая неподтверждённая отправка возвращает заполненную форму и видимую
  кнопку подтверждения;
- введённые флаги, области, статусы и описания сохраняются между двумя шагами;
- версия формы и `base_hash` проверяются до разбора checkbox-полей;
- сервисный слой повторно проверяет `base_hash` перед атомарной записью;
- руководство администратора, POLICY_MODEL и ADR-0034 актуализированы.

## Приёмка

- `make check` — успешно;
- затронутые классы — 24 теста успешно;
- независимая проверка управления доступом — PASS по 5 пунктам;
- полный набор — 553 теста и 75 подтестов успешно, 2 известных несвязанных
  падения AI UI из-за старых ожиданий версий статических файлов.
