# Отчет исполнения пакета 02

## Результат

Плоский фильтр и переключатель вида заменены вложенным фильтром подразделений в левой
панели канбана. Добавлены поиск без серверного запроса, выбор ветвей, сброс, пустые
состояния, общий GET/HTMX-контракт и мобильный диалог с фоном и удержанием фокуса.

Общий код канбана и `workordersChanged` перенесен в `workorder_board.js`; старые шаблоны
дерева и `workorder_tree.js` удалены.

## Проверки

- синтаксис новых JS-файлов проверен через `node --check`;
- браузерный сценарий проверяет URL/reload, локальный поиск, внешние form-associated
  controls, клавиатуру, размеры целей и мобильный слой;
- `make check` проходит после синхронизации `staticfiles/`.
