# Отчет исполнения: диагностика SSO

Проверена цепочка IIS Windows Authentication → `REMOTE_USER` → Django session.
В руководство добавлены различимые причины появления формы входа:

- сохраненный признак ручного входа в Django-сессии;
- неверный `DJANGO_AUTH_MODE` или состав middleware/backend;
- анонимный доступ на рабочем URL из-за IIS inheritance;
- отсутствие автоматической передачи учетных данных браузером;
- рассогласование URL, DNS, binding, SPN и Windows Auth providers;
- отключенная локальная учетная запись.

Добавлена диагностическая развилка по приватному окну и полю `cs-username` в
журнале IIS. Настройки конкретного хоста не изменялись без его журналов.
