# Базовый просмотр канбана и диагностика SSO

## Цель

Дать пользователю без назначенной роли минимальный доступ только на чтение
канбан-доски и подготовить проверяемое объяснение причин появления формы входа
вместо Windows SSO.

## Объем

- базовая область просмотра по ветке подразделения;
- только доски, разрешенные группе `customer`;
- запрет всех write-действий и скрытие кнопки создания;
- отображение базового источника в «Итоговом доступе»;
- серверные и HTTP-тесты;
- уточнение диагностического дерева IIS/браузер/Django в руководстве SSO.

## Вне объема

- изменение host-specific `web.config` или настроек целевого IIS без журналов;
- автоматическая выдача роли `customer`;
- изменение контрактов ролей или схемы базы.

## Приемка

1. Пользователь без роли и с рабочим подразделением видит заявки только своей ветки.
2. Он не может создавать, редактировать, комментировать или менять статусы.
3. Закрытая доска без группы `customer` остается недоступной.
4. Пользователь с явной ролью работает только по правилам этой роли.
5. Итоговый доступ объясняет базовый профиль.
6. Руководство SSO различает отсутствие `REMOTE_USER`, ручной режим сессии,
   отключенную учетную запись и проблемы Kerberos/IIS.
