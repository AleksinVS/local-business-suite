# Ретроспектива

Статус: archived.

Дата: 2026-07-30.

Основная стоимость была не в количестве тестов, а в production password hasher и повторном создании схемы SQLite. Наибольший эффект дали отдельные test settings и файловая reusable test DB.

Глобальная замена файлового storage на in-memory оказалась несовместима с содержательным тестом удаления файла с диска. Решение заменено на реальный FileSystemStorage с путем в `.local/test-media`.

Перенос фикстур выявил два теста, где ожидаемый доступ к листу ожидания не соответствовал действующему контракту ролей. Тесты переведены на пользователя с capability роли врача; production-политика не менялась.

Параллельный pytest оставлен только экспериментальной командой: в проекте есть тесты общего файлового и модульного состояния, поэтому включать xdist по умолчанию преждевременно.
