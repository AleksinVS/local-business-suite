# Отчёт исполнения

## Реализовано

- поля записи встроены непосредственно в панель просмотра;
- кнопка «Редактировать» удалена, сохранение не закрывает панель;
- пользователю без права изменения возвращается режим только чтения;
- один шаблон полей используется при создании и редактировании;
- ошибки проверки остаются в панели вместе с введёнными значениями;
- обновление записи выполняется под `select_for_update` в транзакции;
- очищение необязательных дат сохраняется;
- аудит перечисляет только фактически изменённые поля и не копирует значения PII;
- отсутствие изменений не создаёт ложную запись аудита;
- сбой аудита откатывает изменение записи;
- после HTMX-сохранения таблица листа ожидания обновляется.
