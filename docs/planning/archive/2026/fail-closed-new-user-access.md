# Закрытый доступ новых пользователей и роль по умолчанию

- Статус: завершено
- Дата завершения: 2026-08-26
- Решение: `docs/adr/ADR-0045-fail-closed-roleless-access-and-new-user-default-role.md`

## Результат

- неявный `default_board_viewer` исключён из runtime-проверок;
- пользователь без контрактной роли не видит рабочую навигацию, данные главной
  страницы и ИИ-панель, а прямой вход в канбан и медизделия запрещён;
- контракт ролей поддерживает безопасную настройку `$defaults.new_user_role`;
- активный суперпользователь меняет настройку в разделе «Доступ» с атомарной
  записью, optimistic lock и аудитом;
- локальное и AD-создание назначают настроенную роль в общей транзакции и пишут
  `AccessAssignmentAudit`;
- миграционный отчёт `viewer` приведён к закрытой исходной модели.

## Проверки

- 440 тестов, 96 вложенных проверок — пройдены;
- профиль `contracts`: 52 теста и 2 вложенные проверки — пройдены;
- `default_board_access_e2e` — пройден;
- полный прогон остановлен до тестов на несинхронизированных `staticfiles/`
  незавершённого AG-UI-контура, который не входит в область этого изменения.
