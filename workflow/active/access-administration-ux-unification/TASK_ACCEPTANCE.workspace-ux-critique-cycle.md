# Приёмка пакетов 06–08: единое окно доступа

## Результат

Реализовано каноническое окно `/settings/access/` с шестью разрезами доступа,
центральной таблицей, правым инспектором объекта и левым редактором значения.
После визуальной приемки размещение уточнено: правый инспектор всегда выезжает
поверх рабочей области по механике канбан-доски, а левый редактор занимает место
дерева подразделений и ИИ-чата; до 1200 px он становится полноэкранным слоем.

Критические инварианты:

- фильтры таблицы пользователей не влияют на полный состав роли;
- пакетное изменение состава роли использует подписанный preview/apply и создаёт
  отдельный `AccessAssignmentAudit` для каждого изменённого пользователя;
- профиль, статус, подразделение и AD identity применяются только после
  подписанного предпросмотра с проверкой устаревшего состояния;
- superuser сохраняет рискованное самоназначение контрактной роли;
- основной интерфейс не пишет производные разделы сайта и общие технические
  группы напрямую;
- Django Admin сохранён как резервный путь через защищённый адаптер.

## Остаточные границы

- общая read-only проекция журналов и расширенные explain-адаптеры остаются в
  пакетах 04/05;
- прямого API записи в Active Directory нет: интерфейс меняет только локальную
  principal-связь;
- общий разрез технических групп остаётся read-only без предметного владельца;
- окончательное архивирование блока выполняется после пользовательской проверки.
