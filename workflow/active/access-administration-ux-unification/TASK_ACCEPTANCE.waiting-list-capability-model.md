# Приёмка: модель прав листа ожидания

Статус: **PASS после штатной миграции runtime**.

Критерии:

- чужая запись не раскрывается через HTTP, правую панель, AI и source adapter;
- несвязанные поля разных ролей не образуют новое разрешение;
- `manage_departments` не влияет на лист ожидания;
- статус нельзя изменить через update;
- переход допустим только при совпадении scope, исходного статуса, target роли и глобального графа;
- stale/inactive actor и stale entry отклоняются сервисом;
- суперпользователь получает полный грант, но не обходит глобальный граф;
- старый runtime читается до миграции, новый контракт не показывает дублирующий legacy-флаг;
- рабочие данные применяются только через preview/CAS/audit Settings Center.

Отдельная проверка Sol не выявила иных блокеров после исправления трёх замечаний финального security review.
