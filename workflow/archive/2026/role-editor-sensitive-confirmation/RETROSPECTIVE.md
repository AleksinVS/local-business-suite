# Ретроспектива

Первоначальный интерфейс ошибочно делал доступность подтверждения зависимой от
JavaScript и после серверного отказа терял состояние через redirect. Надёжный
шаблон — серверный повторный рендер с отдельным подтверждающим submit.

Остаточный риск: при несовместимом изменении POST-семантики разработчик должен
повысить `ROLE_RULES_FORM_VERSION`. Изменение рабочего контракта независимо
защищено `base_hash`. Два известных падения AI UI не связаны с редактором ролей
и остаются отдельной задачей.
