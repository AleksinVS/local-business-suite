# Workflow: закрытый доступ новых пользователей

## Цель

Закрыть неявный продуктовый доступ без роли и добавить управляемую роль новых
пользователей по умолчанию.

## Область

Контракт ролей, политики и HTTP-доступ workorders/inventory/core, создание
локальных и AD-пользователей, единый интерфейс доступа, аудит, тесты и
документация.

## Итог

Цель достигнута. Массовое назначение ролей существующим пользователям не
выполнялось.
