# Waiting list inline editing

## Цель

Встроить редактирование записи в окно просмотра и сделать аудит фактических изменений атомарным.

## Scope

- Read/write: `apps/waiting_list/`, `templates/waiting_list/`, целевые стили и тесты.
- Read-only: политики доступа, общая оболочка правой панели.
- Не менять схему БД, роли и статусы.

## Риски

- потеря очищенных необязательных значений;
- ложные записи аудита при сохранении без изменений;
- частичное сохранение без аудита;
- обход прав прямым POST;
- вывод персональных значений в журнал.

## Проверки

- `make verify-fast TEST_SCOPE=apps/waiting_list/tests.py`;
- `make verify-profile PROFILE=ui`;
- Playwright: просмотр → встроенное изменение → сохранение → история;
- один `make verify-full` перед технической приёмкой.
