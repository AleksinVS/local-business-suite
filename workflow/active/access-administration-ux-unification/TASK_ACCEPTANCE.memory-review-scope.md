# Приёмка: область ревью памяти

## Вердикт

Принято. Техническая группа ревью не отменяет продуктовую роль, adapter policy,
область источника и объекта. Все критичные чтения и записи используют свежего
активного пользователя; текущая и предлагаемая ACL повторно проверяются под
блокировкой. Неопределённая ACL закрывается согласно явной политике источника.

История Git, карточки issue/document, assignees и reindex/delete не раскрывают
чужие personal или предметные данные. Прямое чтение текста документа также
actor-aware.
