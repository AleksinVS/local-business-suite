# Block Brief: обязательное подразделение пользователя

## Цель

Сделать `User.department` обязательным без расширения доступа старых пользователей.

## Write scope

- `apps/accounts/`, формы и шаблоны Settings Center;
- ADR-0035, POLICY_MODEL, пользовательская документация;
- planning/workflow и структура проекта.

## Риски

- автоматическое назначение корня расширяет `department_branch`;
- `PROTECT` меняет удаление подразделений;
- AD и служебные команды создают пользователей без явного подразделения;
- миграция должна одинаково работать в SQLite и PostgreSQL.

## Приёмка

Старые `NULL` перенесены в карантин, новые формы требуют реальное подразделение,
программное создание работает fail-closed, тесты и PostgreSQL e2e зелёные.
