# Отчёт исполнителя: 02-role-card-editor-and-preview

## Выполнено

- Широкая матрица заменена карточками ролей, сгруппированными по серверным
  метаданным `section`; технические коды разделов переведены в понятные русские
  названия.
- Для каждого права доступны описание, значение и риск-маркер: `elevated` —
  предупреждение, `critical` — обязательное подтверждение.
- Предпросмотр в браузере показывает выдачу, отзыв и изменение права; число
  затронутых сотрудников считается как объединение уникальных пользователей
  всех изменённых ролей.
- Сервер требует `base_hash`, повторно вычисляет diff по текущему контракту и
  отклоняет прямой POST критического права без `confirm_sensitive_changes=yes`.
  `action=preview` не записывает контракт.
- На странице показан журнал `SettingsChange` для `core.contract.role_rules`.
- Список участников ролей собирается одним запросом, без N+1.

## Проверки

- `make test-fast TEST_SCOPE='apps/core/tests.py::RoleRulesCapabilityUiTests'`:
  9 passed.
- `make test-fast TEST_SCOPE='apps/core/tests.py'`: остановлен на внешнем
  падении `DemoSeedCommandTests.test_seed_demo_data_flush_removes_marked_objects`:
  `ProtectedError` при удалении подразделения из `seed_demo_data --flush`.
  Падение воспроизведено через `make test-failed`; оно относится к параллельным
  изменениям моделей `accounts` и не входит в write scope пакета.
- `make check`: Django check успешен; `check_staticfiles` ожидаемо не пройден,
  поскольку `staticfiles/` уже рассинхронизирован с `static/src/` и сборка
  статических файлов не входит в write scope.
