# Техническая приёмка: warehouse implementation

- Статус: принято с зафиксированными ограничениями среды
- Дата: 2026-08-31

## Принято

Критерии общего продукта выполнены: права закрыты по умолчанию, операции и
отчёты ограничены областью подразделений, журнал неизменяем, отрицательный
остаток запрещён, сторно проверяет точное соответствие исходнику, CSV/XLSX
защищены от формул, а legacy commit проходит только через доменный сервис.

## Ограничения и остаточный риск

1. Конкурентные блокировки реализованы для PostgreSQL, но локальная SQLite не
   воспроизводит настоящую гонку `select_for_update`; это проверяется в CI или
   перед внедрением на PostgreSQL.
2. Приватный VOB3 dry-run и сверка не входят в приёмку кода и выполняются только
   как операция конкретного внедрения.
3. Общий `manage.py test` на этой Windows-машине падает внутри нативной LanceDB
   (`0xc000001d`). Набор затронутых модулей выполнил 438 тестов; три складские
   регрессии исправлены, девять оставшихся падений относятся к ранее
   существующим viewer-migration и удержанию временных SQLite-файлов Windows.

Остаточные пункты не блокируют техническую приёмку складского домена, но должны
быть видимы в CI/внедрении.
