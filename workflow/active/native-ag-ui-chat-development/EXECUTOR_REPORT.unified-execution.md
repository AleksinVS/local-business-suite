# Отчёт исполнения: единый native-контур ИИ-чата

## Статус

Реализация пакетов 06–08 завершена 2026-08-26.

## Результат

- Боковая панель и полная страница используют один сценарий:
  `prepare turn` → Django `run` → agent runtime `/ag-ui`.
- Добавлена модель `ChatRun`: уникальный `(session, run_id)`, состояния запуска,
  сохранённые события и воспроизведение завершённого результата. Условное
  ограничение БД и блокировка сессии допускают только один `RUNNING` на сессию.
- Потерянный после prepare ответ восстанавливается из самого старого
  `PREPARED`-запуска без повторного пользовательского сообщения.
- Django проверяет владельца и активность сессии, совпадение `threadId`, строит
  историю до точного пользовательского сообщения и фиксирует модель при prepare.
- Серверный actor и контекст страницы подписаны; native tool-вызов допускается
  только для соответствующего выполняющегося `ChatRun`.
- Поток Django пропускает только разрешённые AG-UI события и не выдаёт сырые
  аргументы, результаты инструментов и технические ошибки.
- Полная страница получила список сессий, изменение названия, удаление,
  безопасный Markdown, команды, вложения и адаптивную компоновку.
- Служебные `ChatMessage.Role.TOOL` сохраняются для истории агента, но не
  выдаются в пользовательской конфигурации после перезагрузки.
- Удалены старые Django `send`/`stream`, `/ai/ui/ag-ui/run/`, runtime `/chat` и
  `/chat/stream`, старый `ai_chat.js` и неиспользуемая форма.

администрирования доступа. После его дальнейших изменений полный Python-набор
прошёл без падений; целевые native e2e выполнялись отдельно и прошли полностью.

## Версии

Закреплённые `@ag-ui/client=0.0.55`, CopilotKit `1.59.5` и
`ag-ui@0.0.55` не менялись. Обновление требует отдельного согласования.

## Остаточный риск

Нужен production smoke SSE через целевой reverse proxy. Он не воспроизводится
достоверно в локальной среде и не блокирует техническую приёмку кода.

Итоговое независимое ревью Sol high: `APPROVE`. Отдельно проверены отсутствие
nullable join под PostgreSQL `FOR UPDATE`, единый порядок блокировок
`ChatSession` → `ChatRun`, откат и граница доверия поля `surface`.
